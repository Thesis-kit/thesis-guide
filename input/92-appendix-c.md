# Appendix C. Authoring and Coverage Notes


This fictional example demonstrates supported document forms. Its topic, narrative and numerical results are synthetic; they are not completed research.

The cover, contents and numbering were generated by the existing pipeline. The examples exercised supported forms, not every possible discipline-specific artifact or every university formatting rule.

## Supported Forms Demonstrated


The main text demonstrated captions, citations, bold and italic text, inline code, paired quantitative comparison, inline mathematics and numbered display equations. Appendices demonstrated attached source files, configuration languages and a repeated-header table.

The blockquote below was an authored synthesis rather than a quotation from an external source. An actual quotation would need precise source attribution and a locator under the applicable rules.

> A timeout described uncertainty at the caller; it did not establish that a transaction had rolled back.

The synthesis illustrated the italic blockquote style. It introduced no additional empirical evidence.

1. Identify the guarantee being claimed.
2. Match each guarantee to an observable invariant.
3. Check the evidence and state remaining uncertainty.
