# Thesis manuscript and writing guides

This repository contains a sample thesis in Markdown and guides for preparing a manuscript for the Metropolia thesis PDF pipeline. The `input/` directory contains chapter files, abstract metadata, references and assets. The sample is illustrative; its content and metadata should be replaced with the student's own work.

The [`pdf/`](pdf/) directory contains [sample PDF output](pdf/thesis.pdf), showing how the manuscript appears after processing with the thesis pipeline.

The `guide/` directory contains:

- [Writing chapters](guide/CHAPTERS.md): section content, regular Markdown syntax, figures, tables, code and mathematics.
- [References and citations](guide/REFERENCES.md): defining sources in one place and citing them by key, with examples.
- [Abstracts and metadata](guide/ABSTRACT-METADATA.md): student and thesis details, bachelor/master selection, and English, Finnish and Swedish abstract settings.
- [Master’s thesis structure and content](guide/MASTER-THESIS-CONTENT.md): the purpose of each section, research questions, methods, evidence, discussion and a self-review checklist.

The included sample selects a **master thesis with an English and Finnish abstract**. Both alternative languages are explained in the metadata guide. This repository provides writing materials and sample PDF output; PDF generation is handled by the thesis pipeline.
